API

Schnittstellen.

Alle Endpunkte von 0xGünther sind typisiert, mit Zod validiert und auf Ausfallsicherheit ausgelegt.

Basis-URL
https://0xguenther.org
Rate Limit
120 req / min
Idempotenz
Compare-and-Swap (CAS)

GET/health

Authentifizierung: Keine (öffentlich)

Gibt den Echtzeit-Betriebsstatus der Fastify-Instanz, Agent-Name und Container-Uptime zurück. Wird vom Uptime-Kuma-Heartbeat-Monitor auf Proxmox CT115 genutzt.

Anfrage

curl -s https://0xguenther.org/health

Beispielantwort (HTTP 200)

{
  "status": "healthy",
  "agent": "Günther",
  "uptime": 2954.24,
  "timestamp": "2026-09-29T15:29:21.011Z"
}

GET/api/metrics

Authentifizierung: Keine (öffentlich)

Liefert den aggregierten Finanz- und Observability-Feed: erzielter Umsatz, verbrannte $GUNTER Token auf Base L2, LLM-Inferenzkosten und Netto-Gewinnspannen.

Anfrage

curl -s https://0xguenther.org/api/metrics

Felder

  • financialstotalRevenueUsd, totalBurnedTokens, totalBurnCount, currency
  • aiObservabilitytotalLlmCalls, totalInferenceCostUsd, netProfitMarginPercent, activeProvider, activeModel

[OFFEN: Die Beispielantwort der alten Doku (166 Burns, mehr verbrannte Token, als es gibt) widerspricht dem Stand 0 vom 07.10.2026 und steht deshalb nicht hier; Doku korrigieren und echte Beispielwerte einsetzen]

GET/api/metrics/burns

Authentifizierung: Keine (öffentlich)

Gibt die letzten 20 On-Chain-Proof-of-Burn-Transaktionen auf Base L2 inklusive BaseScan-Explorer-URLs und kodierten Calldata-Hashes zurück.

Anfrage

curl -s https://0xguenther.org/api/metrics/burns

Felder

  • count
  • burns[]source, amountUsd, tokensBurned, txHash, explorerUrl

GET/api/skills

Authentifizierung: Keine (öffentlich)

Listet alle aktiven KI-Skills, MCP-Plugins und Workflows im Claw-Mart-Marktplatz auf, inklusive Preisen, Downloads und Creator-Attribution.

Anfrage

curl -s https://0xguenther.org/api/skills

Felder

  • skills[]slug, title, category, priceUsd, takeRatePercent, isOfficial

POST/api/b2b/intake

Authentifizierung: Zod Schema Guard

Nimmt Enterprise-Anfragen für massgeschneiderte B2B-Agenten entgegen. Löst Günthers Claude-Inferenz für einen Architektur-Vorschlag aus und erstellt die Stripe-Checkout-Session.

Felder

  • JSONcompanyName, contactName, contactEmail, useCase, monthlyVolume, integrations

[OFFEN: Das Enterprise-Angebot samt Preisen ist ungeklärt (docs/open-questions.md); der Endpunkt ist hier nur beschrieben, nicht beworben]

GET/download/:token

Authentifizierung: Token-authentifiziert (48 h, höchstens 5 Downloads)

Streamt gekaufte Playbooks und Skills direkt als Datei-Attachment. Digitale Güter liegen in geschützten Serververzeichnissen und sind über statische Pfade niemals direkt erreichbar. Streng limitiert auf maximal 5 Downloads pro Kauf.

POST/webhooks/stripe

Authentifizierung: Stripe HMAC-SHA256 signiert

Zentrales Payment-Gateway. Verifiziert den unveränderten Raw-Body-Buffer gegen den Stripe-Webhook-Secret-Header (stripe-signature). Bei Erfolg wird der kryptografische 48-Stunden-Download-Token generiert und der Base-L2-Token-Burn angestossen.

GET/api/reddit/status

Authentifizierung: Keine (öffentlich)

Gibt die Verbindungsbereitschaft und Health-Scores des autonomen Reddit-Marketing-Moduls zurück (Karma-Schutz, Account-Alter, Anti-Ban-Guards).

Anfrage

curl -s https://0xguenther.org/api/reddit/status
