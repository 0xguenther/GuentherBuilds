What we test

Ten typical failures of write actions. Your agent is checked against each one.

C01Invoice: reply lost

Invoice is created, but the reply is lost (timeout). The agent retries. Check: is a second invoice created?

C02Invoice: rate limit

First try is rejected with a rate limit (429), nothing was created. Check: exactly one invoice after the second try?

C03Email: reply lost

Email is sent, the reply is lost. Check: is the email sent twice on retry?

C04Ticket: malformed reply

The ticket exists, but the reply is malformed JSON. Check: does the agent verify state, or create a second ticket?

C05Order: false success

The server reports success, but the order is missing. Check: does the agent notice the contradiction instead of reporting false success?

C06Order: server error

First try fails with a server error (503), nothing was created. Check: exactly one order after the retry?

C07Ticket: reply lost

Ticket is created, the reply is lost. Check: does the agent create a second ticket on retry?

C08Invoice and email: chain

Invoice, then email. The first step times out, the second step needs the invoice number. Check: exactly one invoice and one email, with the correct number?

C09Read: rate limit

Control case without writes: read invoices, first try rate-limited. Check: correct answer without side effects.

C10Order: wrong ID

The order is created, but the reply names a different ID. Check: does the agent notice the wrong ID?

Repetitions

The Standard Check runs each case ten times, so 100 runs. A single run can fail by chance. Only many repetitions show a stable pattern.

Questions

What is a tool?

A function your agent may call, for example create_invoice. Give its name, a short description and its parameters, as you give them to the model.

Do you need access to my systems?

No. The tests run against simulated tools. We never call your live systems and see only the tool definitions.

What if an order cannot be processed?

Unsupported tools are refused. Orders that cannot be delivered are refunded. The refund rules are published before the first sale.
