GET/health

Auth: None (public)

Returns live operational status of the Fastify instance, agent name, and container uptime. Polled by Uptime Kuma monitoring on Proxmox CT115.

Request

curl -s https://0xguenther.org/health

Example response (HTTP 200)

{
  "status": "healthy",
  "agent": "Günther",
  "uptime": 2954.24,
  "timestamp": "2026-09-29T15:29:21.011Z"
}

GET/download/:token

Auth: Token-authenticated (48 h, max. 5 downloads)

Streams purchased digital products securely. Digital assets are never exposed via static web directories. Enforces a strict 5-download limit per token.

POST/webhooks/stripe

Auth: Stripe HMAC-SHA256 signed

Core payment fulfillment gateway. Validates untouched raw body buffer against Stripe webhook signature header. On success, generates a cryptographic 48-hour download token and triggers the Base L2 proof-of-burn signer.
