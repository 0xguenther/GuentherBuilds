GET /health
Authentifizierung: Keine (Öffentlich)

Gibt den Echtzeit-Betriebsstatus der Fastify-Instanz, Agent-Name und Container-Uptime zurück. Wird vom Uptime Kuma Heartbeat-Monitor auf Proxmox CT115 genutzt.

cURL Anfrage: 
curl -s https://0xguenther.org/health
Antwort (HTTP 200 OK):
{
  "status": "healthy",
  "agent": "Günther",
  "uptime": 2954.24,
  "timestamp": "2026-09-29T15:29:21.011Z"
}

POST /api/b2b/intake
Authentifizierung: Zod Schema Guard

Nimmt Enterprise-Anfragen für massgeschneiderte B2B-Agenten ($2,000 Setup + $500/Mo) entgegen. Triggert automatisch Günthers Claude-Inferenz zur Generierung eines massgeschneiderten Architektur-Proposals und erstellt die Stripe-Checkout-Session.

JSON Payload Schema:
{
  "companyName": "Swiss Fintech AG",
  "contactName": "Marc Meier",
  "contactEmail": "marc@swissfintech.ch",
  "useCase": "Customer Support Autopilot mit ERP-Anbindung",
  "monthlyVolume": "1,000 - 10,000",
  "integrations": "Stripe, HubSpot, PostgreSQL"
}
POST /webhooks/stripe
Stripe HMAC-SHA256 Signiert

Zentrales Payment-Gateway. Verifiziert den unveränderten Raw-Body-Buffer gegen den Stripe Webhook Secret Header (stripe-signature). Bei Erfolg wird der kryptografische 48-Stunden-Download-Token generiert und der Base L2 Token Burn angestossen.

GET /download/:token
Token-Authentifiziert (Einmalig / 48h)

Streamt gekaufte Playbooks und Skills direkt als Datei-Attachment. Digitale Güter liegen in geschützten Serververzeichnissen und sind über statische Pfade niemals direkt erreichbar. Streng limitiert auf maximal 5 Downloads pro Kauf.
